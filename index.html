Cara Pasang Domain & Online-kan Undangan

Panduan praktis agar undangan Anda bisa dibuka oleh semua tamu di HP mereka.

Cara 1: Vercel / Netlify (1 Menit Jadi - 100% Gratis) Paling Direkomendasikan
  1. Buka situs vercel.com atau netlify.com/drop.
  2. Daftar akun gratis (cukup masuk menggunakan akun Google / GitHub).
  3. Tarik (*drag & drop*) folder project nikah-invitation ke browser.
  4. Dalam 30 detik, undangan Anda langsung aktif di link domain gratis seperti: https://radit-nabila.vercel.app!
Cara 2: GitHub Pages (Gratis Selamanya) Tanpa Biaya Bulanan
  1. Buka halaman pembuatan repo di Chrome: Klik di sini (https://github.new)
  2. Beri nama repository (misal: undangan-nikah), pilih Public, lalu centang Add a README file dan klik Create repository.
  3. Di halaman repo yang terbuka, klik Add file ➜ Upload files, lalu seret berkas index.html dan invitation.html (atau download nikahku-project.zip).
  4. Klik tombol hijau Commit changes.
  5. Masuk ke Settings ➜ Pages (di menu atas), pada opsi Build and deployment -> Branch pilih main / root lalu klik Save.
  6. Selesai! Undangan Anda langsung aktif online di link: https://username.github.io/undangan-nikah/invitation.html
Cara 3: Beli Domain Sendiri (.com / .id / .my.id) Paling Mewah & Eksklusif

Ingin nama domain sendiri tanpa embel-embel seperti https://raditnabila.com atau https://raditnabila.my.id?

  • Beli domain murah (mulai Rp 12.000 - Rp 30.000/thn) di Niagahoster, Domainesia, atau IDwebhost.
  • Di Vercel atau GitHub Pages, buka tab Custom Domains dan ketikkan domain Anda.
  • Tautan yang Anda bagikan ke para tamu lewat WhatsApp akan tampil dengan nama domain resmi Anda!
